## 简介

PDF Blender 让 PDF 保持清晰易读，同时提高内容被直接复制和提取的难度。你可以调整页面尺寸、将页面图片化、添加水印、定制复制层，并设置元数据和阅读器权限。PDF 不会离开你的设备。它不是加密或 DRM，无法阻止截图、OCR 或所有形式的复制。

## 功能

- 将页面调整为 A4 等常用纸张尺寸，或统一页面宽度。
- 以可调图片质量将页面图片化。
- 添加单个大水印或重复排列的多个小水印。
- 定制复制层：文字布局扰动、随机 Unicode、纯数字、纯字母或自定义警示文字。
- 应用像素噪点、纹理变化和几何扰动。
- 添加用于研究和实验的隐藏提示词，不承诺特定 AI 响应。
- 设置文档元数据、版权信息和阅读器权限。
- 在本机处理 PDF，不上传文档内容。

## 隐私与使用边界

PDF Blender 不会上传 PDF 内容。它旨在增加内容被复制和提取的难度，但不提供加密、访问控制或 DRM 保护，也无法阻止截图、OCR 或其他所有复制方式。详情请阅读[隐私政策](https://pdf-blender.vercel.app/privacy)。
