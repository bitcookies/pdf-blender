## 简介

PDF Blender 可在尽量保持页面可读的同时，增加 PDF 内容被复制和提取的难度。你可以统一页面宽度或调整为常用纸张尺寸、将页面图片化、添加水印，并设置复制层、元数据及 PDF 权限。所有处理均在本机完成。PDF Blender 不提供加密或 DRM 保护，无法阻止截图、OCR 或所有形式的复制。

## 功能

- 统一页面宽度，或将页面调整为 A4 等常用纸张尺寸。
- 将页面图片化，并设置图片质量。
- 添加单个大水印或重复排列的多个小水印。
- 设置复制层，包括文字布局扰动、随机 Unicode、纯数字、纯字母和自定义警示文字。
- 使用像素噪点、纹理变化和几何扰动调整页面视觉效果。
- 添加隐藏提示词文本作为研究性功能；不保证 AI 系统会遵循这些内容。
- 设置文档元数据、版权信息和 PDF 阅读器权限。
- 在本机处理 PDF 文件。

## 隐私与使用边界

PDF Blender 在本机处理文件，不会上传 PDF 内容。它旨在增加内容被复制和提取的难度，但不提供加密、访问控制或 DRM 保护，也无法阻止截图、OCR 或其他所有复制方式。详情请阅读[隐私政策](https://pdf-blender.vercel.app/privacy)。
